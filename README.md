# Misha & Ksyusha — wedding book

Interactive wedding scrapbook with page turning and a mobile reading mode.

## Preview

Published with GitHub Pages from the main branch, repository root.

## Files

- index.html, style.css, reader.css: browser interface.
- content.js: Russian copy and photograph captions.
- paint.js, pen-marks.js: shared page compositions and hand-drawn details.
- engine.js: page-turning mechanics.
- reader.js: continuous mobile reading with the same compositions.
- app.js, counter.js: interactions and elapsed-time counter.
- assets/: optimized images, local fonts and font licenses.

Static concept: voice recording, accounts, private storage and timed delivery are not implemented.

Paper-fold mechanics adapted from the user-provided New Zealand sketchbook by Ann Nguyen (https://www.bubbbly.com/app/nz-sketchbook.html). Photos supplied by the client. Decorative raster assets generated for this project; envelope addresses moved locally. Caveat, Bad Script and Marck Script fonts are distributed under SIL OFL; licenses are in assets/.
